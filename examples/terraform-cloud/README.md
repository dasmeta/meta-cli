# Terraform Cloud driver examples

Based on [terraform-tfe-cloud/tests/basic](https://github.com/dasmeta/terraform-tfe-cloud/tree/main/tests/basic) and linked-workspace patterns from driver tests.

## Variants

| Folder | Modules | Linking |
|--------|---------|---------|
| [basic/](./basic/) | `group-0/module-a` | none |
| [advanced/](./advanced/) | `group-0/module-a`, `group-0/module-b` | `linked_workspaces` + `${group-0/module-a[...]}` interpolation |

## Layout (each variant)

```text
.
├── metacloud.yaml
├── _metacloud.tf              # generated by meta init
├── _.yaml
└── group-0/
    └── module-a.yaml            # + module-b.yaml in advanced/
```

YAML files sit in the example root (default `yaml_dir: .`).

## Commands

```bash
cd basic   # or advanced/
meta init
meta validate
meta plan --setup group-0/module-a
meta apply --setup group-0/module-a,group-0/module-b   # advanced
```

`meta plan`, `meta apply`, and `meta destroy` print a warning for this driver — use the Terraform Cloud UI for manual runs.
